OpenSASI Open Student-Amateur Space Initiative. sfsim is a realistic 3D space flight simulator. LunCo is an open-source, high-fidelity robotics co-simulation platform built for System-Level Engineering and Concept of Operations (CONOPS). OpenSpace is an open source astrovisualization project. NVIDIA PhysicsNeMo is an open-source deep-learning framework for building, training, fine-tuning, and inferring Physics AI models using state-of-the-art SciML methods. LBR-26 Ground Software is a ground-side software stack. Astraeus-I avionics development board. Advanced flight computer software for high-powered rockets. Practical calculation of the aerodynamic characteristics of slender finned vehicles. Nonlinear simulation of hypersonic flight dynamics, made with MATLAB and FlightGear. EnSim is an open-source desktop application for rocket propulsion analysis and flight simulation. MAPLEAF 6-DOF Rocket Flight Simulation Framework. GUI_Missile_Flyout is a stand-alone program running under Windows for simulating ballistic missiles. The Cambridge rocketry simulator can be used to produce six-degree-of-freedom simulations of rocket flights. TrinetraOne is a custom-designed rocket. RocketPy is the next-generation trajectory simulation solution. MATLAB/Simulink simulation software for the flight dynamic simulation of an transsonic missile system. JSBSim Manager. FreeCAD Rocketry Workbench. The Aerobee was a name given to a family of sounding rockets with several variants flow in the 1960's. FC-Udev Flight Software is an open-source project designed to operate and manage model rockets. NASA simulation test cases to JSBSim 

The directory structure includes a specific folder for each phase of development and engineering programs:

- __MBSE__: The root folder Arcadia (ARChitecture Analysis and Design Integrated Approach) is a method of tools dedicated to systems engineering and architecture, supported by the Capella modeling tool.    
  - __CAD__: For computer-aided design.
  - __CAM__: Dedicated to the part manufacturing and assembly process.
  - __CAS__: For simulation of end-to-end functionality and performance analysis.
